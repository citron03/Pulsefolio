# Pulsefolio 기획서 (PRD)

> 개인 투자자를 위한 현실적인 투자 관리 & 시장 모니터링 플랫폼  
> 버전: v1.1 / 상태: 기획 확정 / 기준일: 2025

## 1. 프로젝트 개요

### 한 줄 정의
실제 거래 없이, 실제 데이터로 내 투자를 관리하는 서비스.

### 목적
- 거래 기능을 배제하고 투자 현황 파악과 시장 모니터링에 집중한다.
- 금융 UX 설계, 데이터 중심 UI, 운영형 서비스 설계를 실제 구현으로 검증한다.

### 핵심 가치
- 현실성: 실제 구현 가능한 범위의 API/데이터만 사용
- 명확성: 핵심 정보 중심의 최소 클릭 구조
- 안정감: 금융 서비스 톤의 신뢰 UI/UX
- 운영성: API 장애, 장 종료, 빈 데이터 등 실제 운영 상황 대응

## 2. 범위 정의

### 포함
- 보유 종목 수동 등록 및 포트폴리오 관리
- 현재가/등락률/거래량 조회
- 관심 종목 등록 및 모니터링
- 국내외 주요 지수 및 환율 확인
- 일봉/주봉/월봉 기반 차트
- 투자 메모 작성/관리
- 시장 상태(장중/장 종료/휴장) 표시

### 제외
- 실제 주문/체결, 계좌 연동, 자동매매
- 실시간 호가 WebSocket(승인/비용/제약 이슈)
- 다중 증권사 통합
- 실시간 체결 엔진

## 3. 데이터 정책

### 메인 소스
- 한국투자증권 Open API (시세, 지수, 환율, 차트)

### 보조 소스
- 환율 보완 API (필요 시)
- DART Open API (실적/배당/일정)

### 갱신 정책
- 주요 지수: 30초 polling
- 관심 종목: 10~30초 polling
- 포트폴리오 평가금액: 30초 재계산
- 차트: 요청 시 fetch
- 시장 캘린더: 1일 1회
- 환율: 1분

### 시장 상태
- 장 시작 전: 전일 종가 기준
- 장중: LIVE + 갱신 활성화
- 장 종료 후: 종가 기준 + 갱신 중단
- 휴장일: 갱신 중단

## 4. 화면 구성
- 로그인/온보딩
- 메인 대시보드
- 포트폴리오 관리
- 종목 상세
- 관심 종목
- 시장 정보
- 검색
- 설정

## 5. 화면별 핵심 요구사항

### 로그인/온보딩
- Google/GitHub 로그인 + 게스트 모드
- 신뢰감 있는 톤(딥블루/화이트/그레이)

### 메인 대시보드
- 자산 요약 카드(총평가/총수익률/일간손익/원금)
- 자산 비중 도넛 차트
- 보유 종목 Top 5
- 시장 지수 바
- 최근 본 종목

### 포트폴리오 관리
- 정렬 가능한 종목 테이블
- 종목 추가 모달(입력 검증 포함)
- 종목별 투자 메모 CRUD

### 종목 상세
- 가격/등락/거래량/거래대금 헤더
- 기간별 차트
- 재무정보(미제공 시 N/A)

### 관심 종목
- 시세 훑기 전용 리스트
- 그룹(최대 3개)
- 급등락 강조

### 시장 정보
- 주요 지수
- 섹터 흐름(정적 매핑 + 동적 시세)
- 시장 캘린더

### 검색
- 종목명/코드 검색 + 자동완성
- 최근 검색어 로컬 저장

### 설정
- 상승/하락 색상 기준
- 라이트/다크
- 갱신 주기
- 알림 on/off
- 계정/데이터 초기화

## 6. 비기능 요구사항
- 모든 fetch 영역에서 `loading/empty/error/stale` 처리
- 초기 로딩 목표: LCP 3초 이내
- 100개 이상 리스트 virtualization
- 모바일 우선 + 반응형
- 접근성: 색상 외 기호 병행, 키보드 탐색

## 7. 리스크 대응
- API 승인 지연: Mock 우선 개발
- 분봉/재무 데이터 제한: 대체 UI 및 N/A 처리
- Rate limit: 캐싱 + polling 주기 제어
- 섹터 API 부재: JSON 수동 매핑

## 8. 마일스톤
- Phase 1(2~3주): 셋업, 인증, Mock, 대시보드, 포트폴리오 CRUD
- Phase 2(2~3주): API 연동, polling, 시장 상태, 차트
- Phase 3(2주): 관심종목/시장정보/검색/설정
- Phase 4(1~2주): 품질/성능/반응형/접근성
