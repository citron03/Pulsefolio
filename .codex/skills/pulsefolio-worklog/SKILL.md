# Pulsefolio Worklog Skill

## 목적
하루 단위 작업 내용을 누락 없이 기록하고, 배포/개발 이력을 추적 가능하게 유지한다.

## 규칙
1. 파일 경로는 `docs/project/logs/YYYY-MM-DD.md`를 사용한다.
2. 날짜는 로컬 타임존 기준으로 기록한다.
3. 최소 항목을 반드시 포함한다:
   - 오늘 목표
   - 수행 작업
   - 검증 결과
   - 배포/운영 이슈
   - 다음 액션
4. 명령 출력 전체를 붙이지 말고 핵심 결과만 요약한다.
5. 민감 정보(토큰/시크릿/개인정보)는 기록 금지.

## 템플릿
```md
# YYYY-MM-DD Worklog

## 오늘 목표
- 

## 수행 작업
- 

## 검증 결과
- 

## 배포/운영 이슈
- 

## 다음 액션
- 
```

## 실행 절차
1. 오늘 날짜 파일이 없으면 생성한다.
2. 있으면 섹션 단위로 업데이트한다.
3. 변경 후 README 문서 인덱스가 최신인지 확인한다.
