# Pulsefolio

실제 거래 없이 실제 데이터로 투자 현황을 관리하는 개인 투자자용 플랫폼.

## Quick Start

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

개발 검증:

```bash
pnpm lint
pnpm typecheck
pnpm test
```
